# Contributing

You need [Bun](https://bun.com).

```bash
bun install
bun run check   # typecheck and the test suite; both must pass
```

Open an issue before a large change, so we can agree on the approach first.

The first time you open a pull request, a bot asks you to sign the
[contributor license agreement](CLA.md) by leaving a comment. It lets the
maintainers relicense contributions in later versions; you keep the copyright
in your work.
