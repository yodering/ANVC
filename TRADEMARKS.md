# Trademark

ANVC™ is a trademark of the ANVC maintainers, the owners of the project at
github.com/yodering/anvc and whoever they pass it to. The Apache-2.0 license
covers the code. It doesn't cover the name.

You can do these without asking:

- Say that your tool works with ANVC, reads ANVC records or is compatible with
  ANVC.
- Use the name to write or talk about ANVC, in articles, talks and videos.
- Fork the code and change it under Apache-2.0.

These need the maintainers' permission:

- Calling a product, fork, service or company ANVC, or a name close enough to
  be mistaken for it.
- Saying or suggesting that the maintainers made or endorse something they
  didn't.

A fork has to use a name of its own. To ask about anything else, open an issue
at github.com/yodering/anvc.
